## Use

Invoke as `research-paper-writing` when drafting or revising any section in
`paper/sections/`, polishing figures/tables, checking claim-support alignment, or
running pre-submission self-review.

Per the skill's own rule, load only the one `references/<section>.md` needed for the
current edit target — not all section guides at once.

## Fit with this project

The skill's **claim-evidence map** output contract
(`Claim: … | Evidence: … | Status: supported/needs evidence`) is the same discipline as
`paper/CLAIMS.md`. Keep them in sync: `CLAIMS.md` is the durable ledger, the skill's map is
the per-edit check. Its "weaken or remove unsupported claims" rule is exactly the guard this
project needs, since most current results are single-seed and `DIRECTIONAL`.
